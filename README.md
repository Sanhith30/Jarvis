## 🔧 TROUBLESHOOTING

### ❓ Music Not Auto-Playing?
**Solution:**
- Ensure good internet connection
- Wait for page to fully load (8-10 seconds)
- Try different music apps: "play on spotify" instead of YouTube
- Check screen resolution (coordinates optimized for 1920x1080)

### ❓ WhatsApp Message Not Sending?
**Solution:**
- Make sure WhatsApp Web is logged in (open manually first)
- Use phone numbers with country code: +919876543210
- Wait for WhatsApp Web to fully load (10 seconds)
- Check internet connection

### ❓ Voice Recognition Not Working?
**Solution:**
- Check microphone is connected and working
- Speak clearly and at normal pace
- Reduce background noise
- Wait for "🎤 Listening..." prompt

### ❓ Commands Not Recognized?
**Solution:**
- Use exact command formats from this guide
- Speak naturally but clearly
- Wait for Jarvis to finish speaking before next command
- Check if feature requires internet connection
